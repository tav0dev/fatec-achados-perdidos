# Marca institucional

A interface usa o arquivo oficial, sem redesenho ou alteração de cor/proporção:

- Página de origem: https://fatecitapetininga.cps.sp.gov.br/quem-somos/
- PNG: https://bkpsitecpsnew.blob.core.windows.net/uploadsitecps/sites/274/2026/01/logo_fatec_itapetininga.png
- Acervo de logotipos: https://www.cps.sp.gov.br/asscom/manuais-assessoria-de-comunicacao/departamentos/logotipos-fatec/
- Manual: https://www.cps.sp.gov.br/asscom/manuais-assessoria-de-comunicacao/

`python manage.py identity` baixa o PNG para `fatec-itapetininga.png`. O comando `init` também tenta obter essa cópia. Até ela estar disponível, o HTML aponta diretamente para o PNG oficial. Assim, a marca não é recriada ou substituída por uma aproximação.

Marcas e direitos pertencem aos respectivos titulares. Consulte as orientações de aplicação do CPS. Consulta das fontes: 10/11/2026.

## SVG CPS — revisão de 15/11/2026

https://bkpsitecpsnew.blob.core.windows.net/uploadsitecps/sites/1/2022/09/logo-cps-2022.svg

É utilizado no rodapé e como ícone da aba. A marca combinada da Fatec e do CPS continua sendo o PNG original. A referência visual do cabeçalho e do menu foi inspecionada com REA; consulte `docs/DESIGN_SYSTEM.md`.
