# Fontes locais

Famílias observadas no tema do site https://fatecitapetininga.cps.sp.gov.br/ em 15/11/2026.

Arquivos de pesos 400 e 700 obtidos pela API CSS do Google Fonts:
https://fonts.googleapis.com/css2?family=Roboto:wght@400;500;600;700&family=Roboto+Slab:wght@400;500;600;700&display=swap

Roboto: licença OFL em `Roboto-OFL.txt`, publicada em https://github.com/google/fonts/blob/main/ofl/roboto/OFL.txt.
Roboto Slab: licença Apache 2.0 em `RobotoSlab-LICENSE.txt`, publicada em https://github.com/google/fonts/blob/main/apache/robotoslab/LICENSE.txt.

Os arquivos são servidos pela própria aplicação; a interface não consulta o Google Fonts em tempo de execução.
